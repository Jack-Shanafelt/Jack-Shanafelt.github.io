LOCAL AI COMPANION · DESKTOP APP

Alice

A local desktop companion that brings chat, voice and personality into one interface.

TECHNOLOGIESPython / Ollama / Piper / Desktop UI
PROJECT FOCUSLocal inference, voice interaction and usable controls

01 / THE PROBLEM

The design challenge.

Bring local conversation and voice into a desktop app that can coexist with games and give the user clear control over listening and memory.

02 / THE APPROACH

How it comes together.

The current Python desktop app uses Ollama for conversation and CPU-based Piper for spoken replies. Game-priority processing, explicit microphone controls and editable personality settings put the runtime behavior in the user’s hands.

  • Streaming text chat, recent recall and private sessions.
  • Hands-free and push-to-talk voice input with visible controls.
  • Adjustable spoken replies, model selection and character settings.

03 / CURRENT STATE

A clear view of the work.

A working local development app. Vision remains a future milestone; legacy VALL-E/XTTS experiments are separate from the current voice engine.
