AI-ASSISTED RPG · PROTOTYPE

Paths of Eternity

Open-ended storytelling with a game engine that keeps the rules and the record.

TECHNOLOGIESUnity / C# / Python / Ollama
PROJECT FOCUSAI integration, deterministic game state and memory

01 / THE PROBLEM

The design challenge.

Let a language model describe an adventure without letting generated prose invent inventory, rewards or completed quests.

02 / THE APPROACH

How it comes together.

A structured Unity–Python turn contract separates proposed actions from resolved game state. Unity validates the mechanics; the local model supplies narration and dialogue. Offline inspection and saved records remain usable without inference.

  • World and character creation with explicit point budgets.
  • Reviewed custom drawbacks tied to implemented check rules.
  • Persistent journals and recall that preserve earlier dialogue.

03 / CURRENT STATE

A clear view of the work.

An evolving prototype. AI recall can still make mistakes; broader combat, crafting and powers remain pending.
