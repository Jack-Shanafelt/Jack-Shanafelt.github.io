TABLETOP STORYTELLING · CREATIVE TOOL

Ridiculous Cipher

An intentionally elaborate cipher tool for increasingly strange tabletop journal entries.

TECHNOLOGIESPython / Tkinter / Reversible transformations
PROJECT FOCUSCreative tooling and reversible text transformations

01 / THE PROBLEM

The design challenge.

Turn a tabletop character’s unraveling journal into a practical tool that can encode and decode increasingly elaborate text.

02 / THE APPROACH

How it comes together.

A Python cipher class composes seeded character substitutions, Caesar shifts, emoji mappings and other reversible transformations. A Tkinter interface exposes the complexity controls without requiring players to edit code.

  • Layered transformations with adjustable complexity.
  • Seeded mappings for repeatable decoding.
  • A desktop interface designed around a creative writing workflow.

03 / CURRENT STATE

A clear view of the work.

A creative puzzle and storytelling tool; it is not intended for protecting sensitive information.
